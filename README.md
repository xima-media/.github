# XIMA

Dresden, Germany • [xima.de](https://www.xima.de/) • [Imprint](https://www.xima.de/impressum)

We are a digital agency specializing in web development and content management solutions. Our open-source work focuses on extending the TYPO3 ecosystem with practical tools for editors, integrators, and developers.

**[All Open-Source Packages & Forks →](https://github.com/xima-media/)**

### 🚀 TYPO3 Extensions

#### Backend & Dashboard

- [Manual](https://github.com/xima-media/xima-typo3-manual): Create editor manuals right in the TYPO3 backend.
- [Content Planner](https://github.com/xima-media/xima-typo3-content-planner): Page status functionality to support the planning of content work, e.g. a migration process.
- [Content Audit](https://github.com/xima-media/xima-typo3-content-audit): Dashboard widget to keep content relevant and up to date.
- [Recent Updates](https://github.com/xima-media/xima-typo3-recent-updates): Dashboard widget to display recently updated elements.
- [Dashboard News](https://github.com/xima-media/xima-typo3-dashboard-news): Display important messages and announcements in the TYPO3 dashboard.
- [Recordlist](https://github.com/xima-media/xima-typo3-recordlist): Quickly create backend modules for advanced record listing.

#### Frontend & Editing

- [Frontend Edit](https://github.com/xima-media/xima-typo3-frontend-edit): Edit menu for editors within the frontend regarding content elements and pages.
- [Page Subscription](https://github.com/xima-media/xima-typo3-page-subscription): Subscribe to page changes and receive notifications.

#### Integration & Utilities

- [Mailcatcher](https://github.com/xima-media/xima-typo3-mailcatcher): Mail log reader for the TYPO3 backend.
- [OAuth2 Extended](https://github.com/xima-media/xima-oauth2-extended): Additional OAuth2 provider with on-the-fly user creation.
- [Goaccess](https://github.com/xima-media/xm-goaccess): Integrates goaccess.io metrics into the backend dashboard.
- [Formcycle](https://github.com/xima-media/xm_formcycle): Include your Formcycle forms in TYPO3.
- [t3api Cache](https://github.com/xima-media/t3api_cache): Cache the API response of t3api.

### 🛠️ Deployment & DevOps

- [Deployer Extended TYPO3](https://github.com/xima-media/xima-deployer-extended-typo3): Common deployer configuration for TYPO3 projects.
- [TYPO3 Docker](https://github.com/xima-media/typo3-docker): Docker images for TYPO3 development.
